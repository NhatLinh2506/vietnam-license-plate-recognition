# Vietnamese License Plate Recognition System

## Giới thiệu

Hệ thống tự động nhận diện biển số xe Việt Nam
ứng dụng trí tuệ nhân tạo.

## Công nghệ

- Python
- YOLO
- PaddleOCR
- OpenCV
- FastAPI
- React
- MySQL

## Chức năng chính

- Nhận diện biển số xe từ hình ảnh
- Nhận diện biển số từ video/camera
- Quản lý phương tiện
- Quản lý lịch sử xe ra/vào
- Thống kê và báo cáo
- Quản lý tài khoản và phân quyền
